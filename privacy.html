นโยบายความเป็นส่วนตัว

ปรับปรุงล่าสุด 2026-10-29

ผู้ให้บริการ: Thammanoon Yonkornburee (GOLFPC)
ติดต่อ: golfpc.inn@gmail.com

GoFlowX / GoFlowX Pro รุ่น Local-First ใช้ข้อมูลในเครื่อง มือถือใช้ใบอนุญาต Pro ที่ตรวจลายเซ็นในเครื่อง เมื่อระบบซื้อผ่าน Google Play เปิดให้บริการ จะใช้ RevenueCat ตรวจสอบใบเสร็จและสถานะสมาชิก โดยส่งรหัสผู้ใช้แบบสุ่มของ SDK ข้อมูลการซื้อ และข้อมูลอุปกรณ์ที่จำเป็นให้บริการดังกล่าว ไม่ส่งรูปโปรไฟล์ GPS หรือประวัติกะไปกับระบบซื้อ เว็บพัฒนาอาจมีโหมดทดลองที่ไม่เรียกเก็บเงิน

ชื่อ รูปโปรไฟล์ กะการวิ่ง ค่าใช้จ่าย EXP รถในโรงรถ จุดโปรด หมุดบ้านและการตั้งค่าเก็บในอุปกรณ์นี้ การถอนแอปหรือล้างข้อมูลอาจทำให้ข้อมูลหาย

GPS ใช้เมื่อคุณกดรับตำแหน่ง เช่น บันทึกบ้านหรือจุดจอดรถ จุดแนะนำในแอปเป็นรายการคัดเลือก ไม่ใช่ข้อมูลจราจร เวลาเปิด หรือจำนวนผู้โดยสารสด เมื่อกดค้นหาหรือนำทาง แอปส่งชื่อสถานที่หรือหมุดปลายทางที่เลือกให้ Google Maps ซึ่งใช้ตำแหน่งตามสิทธิ์ของอุปกรณ์และอาจต้องใช้อินเทอร์เน็ต

โฆษณาแสดงเฉพาะผู้ใช้ฟรี รายการสปอนเซอร์และสถิติจำนวนการเห็น/การคลิกเก็บในเครื่อง ไม่ส่งสถิติไปยังเครือข่ายโฆษณา หากยินยอมจึงจะส่งสถิติการเห็น/คลิกไปยัง Cloudflare ของผู้ให้บริการ GoFlowX หากมีการตั้ง API รายการสปอนเซอร์ ระบบจะดึงรายการผ่าน HTTPS และเก็บไว้ใช้ออฟไลน์ เมื่อกดเปิดเว็บไซต์พาร์ทเนอร์ เบราว์เซอร์จะเชื่อมต่อปลายทางซึ่งมีนโยบายของตนเอง รุ่นนี้ยังไม่ใช้ AdMob SDK

ราคาน้ำมันอาจอัปเดตจากบางจากเมื่อเชื่อมต่ออินเทอร์เน็ต โดยไม่ส่งชื่อ พิกัด หรือประวัติทริปไปกับคำขอ

การเปิดแอปแผนที่ โทร แชร์ หรือบันทึกรูปเป็นการกระทำตามปุ่มที่คุณเลือก แอปปลายทางมีเงื่อนไขและการเชื่อมต่อของตนเอง

สถิติทางเลือกเพื่อพัฒนาแอป

ค่าเริ่มต้นปิดการส่งข้อมูล เมื่อคุณเลือกยินยอม แอปส่งรหัสเครื่อง UUID สุ่ม (ไม่ใช่ Advertising ID), เวอร์ชันและหมายเลขบิวด์แอป เวลาและลำดับเหตุการณ์เพื่อจัดข้อมูลที่ส่งล่าช้า วันที่และชั่วโมงไทยที่ใช้งาน, โซน GPS เฉพาะการสแกนเรดาร์ที่ปัดเหลือทศนิยม 2 ตำแหน่ง, ประเภทพลังงาน อัตราสิ้นเปลือง กำไรต่อกิโลเมตร/ชั่วโมงและระยะเวลากะที่คุณกรอก รวมทั้งฟีเจอร์ที่ใช้และรหัสแคมเปญที่เห็น/คลิก ไปยัง Cloudflare ของ GoFlowX ผ่าน HTTPS เพื่อปรับปรุงเรดาร์ เกณฑ์คำนวณงาน และวัดผลงานสปอนเซอร์ ข้อมูลนี้ใช้นามแฝงและยังเชื่อมโยงกันได้ จึงไม่ถือว่านิรนามสมบูรณ์

ไม่ส่งชื่อ รูป เบอร์โทร หมุดบ้าน จุดจอด พิกัด SOS เนื้อหาไฟล์สำรอง หรือยอดรายรับรายจ่ายเต็มรายการผ่านระบบสถิติ คิวออฟไลน์เก็บไม่เกิน 100 รายการ/35 วัน ระบบเก็บข้อมูลที่เชื่อมโยงเครื่องและรหัสที่แฮชสำหรับกันซ้ำไม่เกิน 35 วัน ส่วนรายงานยอดรวมรายวันไม่มีรหัสเครื่องเก็บไม่เกิน 365 วัน และแสดงเฉพาะโซนที่มีอย่างน้อย 3 เครื่องต่อช่วงเวลาในรายงาน 7 วัน ไม่ติดตามตำแหน่งเบื้องหลัง Cloudflare อาจประมวลผล IP ในการรับคำขอและป้องกันการใช้งานผิดปกติ โดยตัวรวบรวมสถิติไม่บันทึก IP ดิบ

ปิดการส่งสถิติในตั้งค่าได้ทุกเมื่อโดยยังใช้แอปได้ครบ ระบบล้างคิวที่ยังไม่ส่งและรหัสสุ่มในเครื่องทันที ความยินยอมไม่อยู่ในไฟล์สำรอง ข้อมูลรวมที่ส่งสำเร็จก่อนปิดจะหมดอายุภายในช่วงเก็บรักษา ติดต่อผู้ให้บริการผ่านหน้าช่วยเหลือเกี่ยวกับสิทธิในข้อมูลของคุณ

การเก็บรักษาและควบคุมข้อมูล

ข้อมูลในเครื่องอยู่จนกว่าคุณจะลบรายการหรือล้างข้อมูลแอป ไฟล์ JSON สำรองและรูปที่ส่งออกต้องลบแยกต่างหาก การล้างข้อมูลไม่ลบประวัติธุรกรรมของ Google Play หรือ RevenueCat และไม่ยกเลิกสมาชิก คุณเพิกถอนสิทธิ์ GPS ผ่านการตั้งค่าอุปกรณ์ได้ แอปไม่ได้ติดตามเส้นทางเบื้องหลังตลอดเวลา

ผู้ให้บริการราคาน้ำมัน รูปสปอนเซอร์ และระบบซื้ออาจได้รับ IP และข้อมูลทางเทคนิคตามคำขอเครือข่าย การจัดเก็บข้อมูลฝั่งบริการเป็นไปตามนโยบายของผู้ให้บริการนั้น หากต้องการเข้าถึง แก้ไข หรือลบข้อมูลที่ผู้ให้บริการประมวลผล ให้ใช้ช่องทางในหน้า ช่วยเหลือ
